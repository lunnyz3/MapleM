# 단계별 구현 계획

- 작성: 2026-10-28, 근거: `legacy-audit.md`, `game-data-audit.md`, `research/nexon-api-audit.md`
- 상태 표기: 미조사 / 조사 완료 / 구현 예정 / 구현 중 / 구현 완료 / 테스트 완료 / 운영 반영 / 보류 / 차단됨
- 운영 반영(배포·재시작·운영 DB 변경)은 매번 운영자 승인 후 진행한다.

## 우선순위 원칙

1. **멈춘 것·틀린 것부터**: 장애, 약관 위반, 잘못된 수치가 새 기능보다 먼저다.
2. **데이터 계층 → 디자인 시스템 → 화면** 순서. 화면부터 만들지 않는다.
3. 경쟁 기능은 "우리 데이터로 정확하게 만들 수 있는 것"부터. 산식을 공개할 수 없는 기능은 추정 모델임을 밝히고 만든다.
