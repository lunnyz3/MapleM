# 메이플스토리M 하드코딩 게임 데이터 전수 조사 (초안)

- 조사일: 2026-10-28 (KST)
- 기준 코드: `worktree-renewal` 브랜치 커밋 `57cb54c`. 아래 줄 번호는 모두 이 커밋 기준이다. 조사하는 동안 같은 작업 트리에서 다른 세션이 `maplestorym.controller.js`, `maplestorym.service.js`, `common.js`, 랭킹 관련 파일을 고치고 있었으므로, 작업본의 줄 번호는 이 문서와 다를 수 있다.
- 범위: `src/controllers/maplestorym.controller.js`, `src/config/starforce-set-options.js`, `src/config/worlds.js`, `src/services/maplestorym.service.js`, `public/js/core/common.js`, `public/js/features/*.js`, `public/js/pages/*.js`, `public/*.html`, `public/assets/` 파일명, `public/probability/*.json` 24개, `chatbot_service/`.
- 방법
  1. 코드 정독과 grep으로 숫자 상수, 목록, 계산식, 확률표를 뽑았다.
  2. 공식 홈페이지 가이드, 패치노트, 공지와 대조했다.
  3. 공식 '확률형 아이템 정보' 큐브 페이지 22개를 헤드리스 브라우저로 읽어 사이트 JSON과 전 행을 자동 대조했다.
  4. Open API는 문서 페이지만 열람했다. API 호출은 하지 않았다.
  5. 보조 근거로 리포 안에 저장된 2026-03-05 실제 API 응답(`debug/mongo_context_all.json`, 이하 "2026-03 샘플")을 썼다. 공식 문서가 아니므로 형식 확인 용도로만 쓴다.
- 검증 상태
  - **일치**: 공식(또는 명시한 근거)과 같음
  - **불일치**: 공식 근거와 다름, 또는 공식 변경 사항이 코드에 반영되지 않음
  - **확인 불가**: 공식 근거를 찾지 못함. 이 상태의 값은 최신이라고 보장할 수 없다.
- 자동 갱신 가능 여부: "가능"은 Open API 응답만으로 하드코딩을 없앨 수 있다는 뜻이다. "부분"은 이름 등 일부만 API로 받을 수 있다는 뜻이고, "불가"는 API에 해당 정보가 없다는 뜻이다(공식 페이지 수동 관리 또는 스크래핑 필요).

파일 표기: 아래 표에서는 파일 이름만 쓴다. `maplestorym.controller.js`, `starforce-set-options.js`, `worlds.js`, `maplestorym.service.js`는 `src/` 아래, `common.js`는 `public/js/core/`, `equipment-shared.js`, `item-share.js`, `guild-shared.js`, `ranking-shared.js`는 `public/js/features/`, `character.js`, `ranking.js`는 `public/js/pages/`, `workflow.py`는 `chatbot_service/`에 있다. 출처는 `[S번호]` 링크로 표기하고, 전체 URL은 7장에 모았다.
