## 하지 않거나 미룬 것
- 같은 유니온 캐릭터(부캐 추정, B F15): 넥슨 유니온 API에 공격대원 캐릭터 목록이 없어 유니온 레벨만으로는 추정이 부정확하다.
- 자유전직 통계(A F38, B F39): 직업 변경 기록이 아직 0건(수집 때 본 변경만 쌓인다). 기록이 쌓이면 통계 탭에 추가.
- 해방일자 랭킹(A F30): 운영자가 원하지 않음.
