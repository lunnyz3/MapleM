- 조사일: 2026-10-28, 방법: 헤드리스 Chromium으로 공개 화면만 직접 조작(로그인·제출·갱신 버튼 미사용, 상대 서버 내부 API 직접 호출 없음)

## 2. A(maplemworlds) 관찰에서 얻은 교훈

- **신뢰의 빈틈**: 랭킹·템환산·전투력 모델·보스 세팅 산식이 비공개이고, 계산기에 패치 버전·확률 출처가 없다. 같은 사이트 안에서도 헥사 가이드와 계산기 값이 다르다. → 우리는 모든 수치에 출처·기준 시각·"공식/계산/추정/직접 입력" 배지를 단다(`design-system.md`의 SourceStamp).
- **랭킹의 성격**: A의 랭킹은 사이트에서 조회된 캐릭터만 모은 자체 DB다. 우리는 공식 랭킹 9종을 정확히 보여주고, 자체 지표는 수집 범위를 밝힌다.
- **데이터 신선도**: A는 갱신 시각을 보여준다(V매트릭스 대조 때 17시간 전 데이터). 우리는 넥슨 반영 지연(평균 10~15분)과 캐시 시각을 함께 보여준다.

## 3. V매트릭스 공격력 % 규칙 대조 (운영자 요청)

| 근거 | 내용 | 판정 |
|---|---|---|
| 우리 규칙 | 장착한 대상 코어마다 공격력 % = 7.6 + 0.6 × (레벨 − 1), 상한 25% | — |
| 운영자 지식 | "쓸만한 ○○ 코어는 공격력 최대 25%" | 상한 일치 |
| 넥슨 공식 가이드 | 공용 코어 최대 30레벨(7/9 개편으로 슬롯 강화 삭제) | 우리 공식은 Lv.30에서 정확히 25.0% → **상한과 최대 레벨이 맞물림** |
| A(maplemworlds) | 코어별 기여를 보여주지 않음. 스킬 '패시브' 합계에 섞여 있을 가능성만 있음(같은 캐릭터 마법 공격력 % 패시브 300%, 우리 V 몫 262%) | 판정 불가 |
| B(maplemtool) | 성장 시뮬레이터에서 코어 레벨을 직접 바꿔 관찰: Lv.1 7.6% / 2 8.2% / 10 13% / 20 19% / 29 24.4% / 30 25%. 대상 10개(쓸만한 8종 + 블링크·로프 커넥트), 에르다 3종·스파이더 인 미러·크레스트 오브 더 솔라 제외. 기본 효과 4종은 더하지 않음 | **공식 일치(레벨별 값·대상)**, 기본 효과는 근거 없음 |
| 결론(2026-10-28) | 공격력 % 규칙은 세 근거(공식 최대 레벨 30, 운영자 지식, B 관찰값)가 일치 → **기본 켜짐**(`VMATRIX_STAT_RULES=off`로 끔). 기본 효과 4종은 근거 없음 → **기본 꺼짐**(`VMATRIX_BASE_EFFECTS=on`으로 켬). 판테온은 7/9 개편으로 사라진 것으로 보이며 목록에 남겨도 영향 없음 | 테스트 `test/vmatrix.test.js` |

## 4. B(maplemtool) 고유 기능과 반영 계획

B는 "계산 전투력" 엔진을 중심에 둔 계산기 사이트다. 넥슨 API의 전투력 값이 실제와 크게 다르다고 보고(예: 같은 캐릭터 API 610만 / B 계산 8.68억 / 공식 전투력 랭킹 12.66억) 자체 모델을 쓴다. 산식과 패치 기준일은 공개하지 않는다.

| 기능 | 우선순위 | 우리 방향 |
|---|---|---|
| 계산 전투력 + 빈칸 채우기(API에 없는 값을 사용자가 입력) | P0 | 공식 전투력 랭킹 값(`character_combat_power`)과 API stat 전투력의 관계부터 조사. 자체 모델은 "추정"으로 표시하고 산식 공개 |
| 스탯 환산(최종 대미지 1%p = 공격력 % x%p = 전투력 +y) | P0 | 위 모델 위에 얹는다. 산식 공개가 차별점 |
| 경험치 고도화(레벨업 예상일, 같은 레벨 대비 백분위, 일일 과제 제외) | P0 | 성장 기록 스냅샷으로 구현 |
| 내 캐릭터·관심·최근 본(브라우저 저장) | P0 | A의 즐겨찾기·최근 조회와 같은 작업 |
| 내실 리포트(영역별 완성도, "다 채우면 전투력 +x") | P1 | 게임 데이터 상한(심볼·HEXA·하이퍼·유니온·링크) 확보 후 |
| 해방 일지(사용자 입력 + 고정 상수로 예정일) | P1 | A의 무기 해방 일정과 합쳐 하나로 |
| 캐릭터 비교(상대 내실이면 얼마나 바뀌나) | P1 | A의 비교와 합침 |
| 보스 컷(다음 보스까지 남은 전투력) | P1 | A의 보스 입장 전투력 표와 합침 |
| 성장 시뮬레이터 축소판(심볼·HEXA·하이퍼·유니온·링크) | P1 | API 값으로 바로 되는 영역부터 |
| 공식 전투력 랭킹 | — | **구현 완료**(2026-10-28, `d7270b1`) |

두 사이트 모두 계산 규칙의 출처·기준일을 밝히지 않는다. 우리는 모든 계산 결과에 근거·기준일·"공식/계산/추정/직접 입력" 표시를 다는 것을 기본 원칙으로 삼는다.
