## C. 알려진 문제(아직 손대지 않음)

- 모바일 랭킹 표에서 큰 수가 줄바꿈된다(디자인 개편 때 한국식 단위 축약).
- 주요 스탯 합산은 일부 출처(직업 패시브 등)가 빠진 추정값이다. 경쟁사 화면과 비교하면 마법 공격력 % 합계가 다르다(우리 405%/143%, 경쟁사 503%). 개편 때 "출처별 합산(일부 출처 제외)"임을 화면에 밝히고 누락 출처를 조사한다.
- 정적 JS 하위 모듈 import에 버전 쿼리가 없어 배포 직후 최대 4시간 옛 파일이 섞일 수 있다(Cloudflare 캐시). Vite 빌드 전환 전까지는 배포 후 Cloudflare 캐시 퍼지를 권장.
- HEXA 응답에 없는 필드(`skill_effect`, `slot_level` 등) 참조, 폐기 예정 필드 사용.
