# 디자인 시스템 — "메이플 하늘 대시보드"

- 작성: 2026-10-28 (초안 v0.1, 구현 전)
- 컨셉: 메이플스토리의 밝고 귀여운 모험 판타지 + 정돈된 고급 데이터 대시보드.
- 원칙: 참고 사이트의 로고·이미지·CSS·레이아웃을 가져오지 않는다. 게임 이미지는 넥슨 API가 주는 캐릭터·아이템 이미지(결과 데이터)만 쓰고, 장식 그래픽과 아이콘은 직접 만든 SVG로 한다.

## 1. 무드

- **하늘과 구름**: 페이지 배경은 크림빛 바탕 위로 아주 옅은 하늘색 그라데이션과 둥근 구름 형태(CSS 그라데이션). 장식은 첫 화면 히어로와 빈 상태 화면에만 쓰고 데이터 화면에서는 절제한다.
- **단풍잎 모티프**: 직접 그린 단풍잎 실루엣을 로고 심볼, 로딩 스피너, 순위 배지 장식에 쓴다.
- **게임 UI의 손맛**: 탭·버튼은 살짝 볼록한 질감(1px 하이라이트 + 부드러운 그림자), 눌림 상태는 1px 내려앉는 효과. 과한 3D·광택은 쓰지 않는다.
- **데이터는 담백하게**: 표·차트·수치 영역은 흰 카드 위 고대비 텍스트. 귀여움은 테두리·아이콘·빈 상태에만.

## 2. 색상 토큰

모든 색은 CSS 변수로 정의하고 컴포넌트는 의미 토큰만 쓴다. 텍스트 대비 4.5:1(본문)·3:1(큰 글씨·아이콘) 이상.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | cream-50 + 하늘 그라데이션 | 페이지 바탕 |
| `--surface` | #FFFFFF | 카드 |
| `--surface-soft` | ink-50 | 카드 안 구획, 표 짝수 행 |

| `--text` | ink-900 | 본문 |
| `--text-muted` | ink-700 | 보조 텍스트(대비 ≥ 7:1) |
| `--text-subtle` | ink-500 | 캡션, 기준 시각(대비 ≥ 4.5:1 확인 후 사용) |
| `--primary` / `--primary-strong` | sky-500 / sky-700 | 버튼 배경 / 링크·강조 텍스트 |

| `--info` | lavender-700 | 안내 |
| `--focus-ring` | sky-300 3px | 키보드 포커스 |

다크 테마는 ink-900 계열 바탕(#17182B), 카드 #202139, 텍스트 #F0F0F8로 같은 의미 토큰을 다시 정의한다. 시스템 설정을 따르고, 수동 전환을 저장한다(기존 테마 토글 유지).

### 2.3 게임 의미 색 (반드시 텍스트·아이콘과 함께)

## 3. 타이포그래피

- 본문·UI: **Pretendard Variable**(SIL OFL, 직접 호스팅 woff2). 숫자는 `font-variant-numeric: tabular-nums`.
- 제목·브랜드: **나눔스퀘어라운드 ExtraBold**(네이버 무료 글꼴, 웹 임베딩 허용 — 적용 전 라이선스 문구 재확인).
- 크기(rem, 기준 16px): 12 캡션 / 14 보조 / 16 본문 / 18 소제목 / 22 카드 제목 / 28 페이지 제목 / 40 히어로. 줄간격 본문 1.6, 제목 1.25.
- 큰 수 표기: 한국식 단위(예: 38억 844만) + 마우스 오버·길게 누르기로 전체 값. 표에서는 단위 축약으로 모바일 줄바꿈을 막는다.

## 4. 간격·모서리·그림자·모션

- 간격: 4px 단위 — 4, 8, 12, 16, 20, 24, 32, 40, 48, 64.
- 모서리: 컨트롤 10px, 카드 16px, 히어로·시트 24px, 배지·칩 999px.
- 그림자(따뜻한 남색 계열): `--shadow-1: 0 1px 2px rgba(35,36,63,.06)`, `--shadow-2: 0 6px 20px rgba(35,36,63,.08)`, `--shadow-pop: 0 12px 32px rgba(35,36,63,.14)`.
- 모션: 호버 120ms, 패널·탭 전환 200ms `cubic-bezier(.2,.8,.2,1)`. 수치 증가 카운트업은 첫 표시 1회만. `prefers-reduced-motion`이면 모두 끈다.

## 5. 레이아웃

- 최대 폭 1200px, 데스크톱 12열 그리드(간격 24px), 태블릿 8열, 모바일 4열·좌우 16px.
- 상단바: 로고 · 통합 검색(월드+이름, 최근 검색·즐겨찾기 드롭다운) · 주요 메뉴 · 테마 전환.
- 모바일: 하단 탭바(홈 / 랭킹 / 계산기 / 내 캐릭터 / 더보기), 검색은 상단 고정 버튼 → 전체 화면 시트.
- 큰 표는 모바일에서 카드 목록으로 바뀐다(순위·이름·핵심 수치 1개 + 펼치기). 가로 스크롤은 마지막 수단.

## 6. 핵심 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| `SearchBox` | 월드 선택 + 이름 입력, 최근 검색·즐겨찾기, 오타 시 안내 |
| `SourceStamp` | 모든 데이터 블록 하단의 "공식 API · 2026-10-28 14:05 기준" 표기와 출처 배지 — 이 사이트의 신뢰 장치 |
| `ProfileCard` | 캐릭터 이미지, 직업 계열 포인트 색, 레벨·경험치 게이지, 월드·길드, 순위 배지 |
| `StatTile` / `StatGauge` | 수치 + 단위 + 변화량(▲▼) / 상한 대비 게이지(상한이 공식 확인된 경우만) |
| `EquipmentGrid` | 게임 장비창 배치를 본뜬 슬롯 그리드 + 프리셋 전환 + 툴팁(모바일은 하단 시트) |
| `GradeBadge` | 잠재 등급·스타포스·랭킹 등급 배지(색 + 글자) |
| `RankBadge` | 1·2·3위 금·은·동 단풍잎 배지, 그 외 숫자 |
| `Tabs` / `Segmented` | 키보드 화살표 이동, ARIA tablist |
| `DataTable` ↔ `CardList` | 데스크톱 표 / 모바일 카드 자동 전환, 정렬·페이지네이션 |
| `TrendChart` | 성장 그래프(SVG). 기록이 없는 구간은 선을 잇지 않고 "기록 없음"으로 표시 |
| `Skeleton` | 카드·표·프로필 모양의 로딩 자리표시 |
| `EmptyState` / `ErrorState` | 구름·단풍잎 일러스트 + 다음 행동 버튼(다시 시도, 다른 날짜 보기) |
| `Toast` / `Sheet` / `Dialog` | 알림, 모바일 하단 시트, 확인 대화상자(포커스 가둠) |

## 7. 아이콘

- 직접 제작 SVG, 24px 격자, 선 굵기 1.75px, 둥근 끝. 기본 세트: 검색, 랭킹(트로피), 길드(깃발), 계산기, 성장(그래프), 장비(투구), 스탯(별), 즐겨찾기(하트), 공유, 다운로드, 설정, 정보, 경고, 확인, 닫기, 화살표.
- 장식: 단풍잎, 구름, 반짝임 3종.

## 8. 접근성 체크리스트

- 색만으로 의미를 전달하지 않는다(배지 글자·▲▼ 기호).
- 모든 상호작용 요소는 키보드로 접근하고 포커스 링을 보인다.
- 이미지에는 대체 텍스트(캐릭터 이미지 = "캐릭터명 캐릭터 이미지").
- 터치 대상 최소 44×44px.
- 표는 `<th scope>`와 캡션을 갖춘다.

## 9. 구현 순서

1. 토큰(`tokens.css`) + 글꼴 + 기본 요소 스타일.
2. AppShell(상단바·하단 탭바·푸터 출처 표기).
3. SearchBox, Card, StatTile, Badge, Tabs, Skeleton, Empty/Error.
4. DataTable↔CardList, TrendChart, EquipmentGrid.
5. 페이지: 메인 → 랭킹 → 캐릭터 상세 → 길드 → 계산기.
