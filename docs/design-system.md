# 디자인 시스템 — "메이플 하늘 대시보드"

- 작성: 2026-10-28 (v0.3 — 랭킹·캐릭터 상세·라이선스 화면, SUIT 제목 글꼴, 인터랙션 반영. 구현하며 바뀐 결정은 각 절에 "구현:"으로 표시하고 11장에 모았다)
- 컨셉: 메이플스토리의 밝고 귀여운 모험 판타지 + 정돈된 고급 데이터 대시보드.
- 원칙: 참고 사이트의 로고·이미지·CSS·레이아웃을 가져오지 않는다. 게임 이미지는 넥슨 API가 주는 캐릭터·아이템 이미지(결과 데이터)만 쓰고, 장식 그래픽과 아이콘은 직접 만든 SVG로 한다.

## 1. 무드

- **하늘과 구름**: 페이지 배경은 크림빛 바탕 위로 아주 옅은 하늘색 그라데이션과 둥근 구름 형태(CSS 그라데이션). 장식은 첫 화면 히어로와 빈 상태 화면에만 쓰고 데이터 화면에서는 절제한다.
- **단풍잎 모티프**: 직접 그린 단풍잎 실루엣을 로고 심볼, 로딩 스피너, 순위 배지 장식에 쓴다.
- **게임 UI의 손맛**: 탭·버튼은 살짝 볼록한 질감(1px 하이라이트 + 부드러운 그림자), 눌림 상태는 1px 내려앉는 효과. 과한 3D·광택은 쓰지 않는다.
- **데이터는 담백하게**: 표·차트·수치 영역은 흰 카드 위 고대비 텍스트. 귀여움은 테두리·아이콘·빈 상태에만.

## 3. 타이포그래피

- 본문·UI: **Pretendard Variable**(SIL OFL, 직접 호스팅 woff2). 숫자는 `font-variant-numeric: tabular-nums`.
  - 구현: npm `pretendard@1.3.9`(OFL-1.1)의 유니코드 범위별 조각(dynamic subset, 92개·총 3.1MB 중 화면에 필요한 조각만 내려받음)을 Vite가 해시 파일로 함께 배포한다. 라이선스 전문은 빌드 때 `/preview/licenses/pretendard-OFL.txt`로 같이 나가고 푸터에서 연결한다.
- 제목·큰 숫자·브랜드: **SUIT**(SIL OFL 1.1, © SUNN, 예약 글꼴 이름 "SUIT"). 토큰 `--font-display`.
  - 구현(v0.3): 나눔스퀘어라운드 계획을 접고 SUIT로 바꿨다(라이선스가 명확하고 숫자 모양이 단단해 큰 수에 맞다). npm `@sun-typeface/suit@2.0.5`(만든 사람이 직접 올린 배포본, 2024-07)에서 **Bold(700)·ExtraBold(800) 원본 woff2 두 개**만 직접 호스팅한다(각 약 170KB, 쓰인 굵기만 내려받음, `font-display: swap`). OFL은 고친 판(글자 잘라내기 포함)에 예약 이름을 못 쓰게 하므로 서브셋을 만들지 않았다. 라이선스 전문은 빌드 때 `/preview/licenses/SUIT-OFL.txt`로 나간다. 적용: h1~h3, 카드 제목, `.display`, 스탯·순위 수치.
- 크기(rem, 기준 16px): 12 캡션 / 14 보조 / 16 본문 / 18 소제목 / 22 카드 제목 / 28 페이지 제목 / 40 히어로. 줄간격 본문 1.6, 제목 1.25.
  - 구현: 대시보드 카드 제목은 **18**로 썼다(22는 카드가 여러 개 놓인 화면에서 무거워 보여 상세 화면 섹션 제목용으로 둔다). 히어로 40은 모바일에서 28.
- 큰 수 표기: 한국식 단위(예: 38억 844만) + 마우스 오버·길게 누르기로 전체 값. 표에서는 단위 축약으로 모바일 줄바꿈을 막는다.
  - 구현 규칙(`web/src/lib/format.js`): 앞에서부터 **단위 묶음 2개**만 보인다(1,153,901,361 → 11억 5,390만, 208,179,041,009,010 → 208조 1,790억, 1,000,000,345 → 10억). **10만 미만은 쉼표 표기**(28,700). 전체 값은 `title`로 보여준다(길게 누르기는 아직 — 11장 남은 과제).

## 4. 간격·모서리·그림자·모션

- 간격: 4px 단위 — 4, 8, 12, 16, 20, 24, 32, 40, 48, 64.
- 모서리: 컨트롤 10px, 카드 16px, 히어로·시트 24px, 배지·칩 999px.
- 그림자(따뜻한 남색 계열): `--shadow-1: 0 1px 2px rgba(35,36,63,.06)`, `--shadow-2: 0 6px 20px rgba(35,36,63,.08)`, `--shadow-pop: 0 12px 32px rgba(35,36,63,.14)`.
- 모션: 호버 120ms, 패널·탭 전환 200ms `cubic-bezier(.2,.8,.2,1)`. 수치 증가 카운트업은 첫 표시 1회만. `prefers-reduced-motion`이면 모두 끈다.
  - 구현: 히어로 단풍잎 3장만 9~11초 주기로 천천히 흔들린다(움직임 줄이기 설정이면 멈춤).
  - 구현(v0.3, `components/Motion.jsx` + `styles/motion.css`, 외부 의존성 없음): 숫자 **카운트업**(처음 보일 때 + 보스 세팅↔현재 착용·직접 입력으로 값이 바뀔 때 이전 값→새 값, 읽기 프로그램에는 최종 값만), **블러 텍스트 등장**(페이지·캐릭터 이름), **스크롤 등장**(IntersectionObserver, 아래에서 14px), **스포트라이트**(마우스를 따라오는 radial 빛, 스탯 타일·랭킹 상위 3·바로가기 타일), **틸트**(최대 4~6°, 캐릭터 그림·상위 3 카드), **자석 버튼**(최대 6px, 검색·반영하기), **오로라 배경**(흐린 색 덩어리 3개가 22~30초 주기로 떠다님, 페이지 머리), **미끄러지는 선택 표시**(탭·구획 선택, transform+width 280ms). 모두 transform·opacity 위주이고, 틸트·자석·스포트라이트는 정밀 포인터(마우스)에서만, `prefers-reduced-motion`이면 전부 끈다. 동작 아이디어는 React Bits를 참고했지만 React Bits는 "MIT + Commons Clause"라 코드는 가져오지 않았다(`/preview/licenses`에 출처).

## 5. 레이아웃

- 최대 폭 1200px, 데스크톱 12열 그리드(간격 24px), 태블릿 8열, 모바일 4열·좌우 16px.
- 상단바: 로고 · 통합 검색(월드+이름, 최근 검색·즐겨찾기 드롭다운) · 주요 메뉴 · 테마 전환.
- 모바일: 하단 탭바(홈 / 랭킹 / 계산기 / 내 캐릭터 / 더보기), 검색은 상단 고정 버튼 → 전체 화면 시트.
  - 구현: 계산기·더보기 화면이 아직 없어 **홈 / 랭킹 / 길드 / 내 캐릭터** 4칸으로 시작했다(빈 탭을 두지 않는다). 상단 검색 버튼은 메인에서는 히어로 검색창으로 이동·포커스한다. 전체 화면 검색 시트는 다른 화면이 생길 때 만든다.
  - 구현: 메인은 12열에서 [히어로 8 | 내 캐릭터 4] → [빠른 조회 4 | 랭킹 바로가기 8] → [랭킹 미리보기 8 | 오늘의 최고 기록 4]. 1080px 미만은 한 열, 720px 미만은 모바일(4열·좌우 16px).
- 큰 표는 모바일에서 카드 목록으로 바뀐다(순위·이름·핵심 수치 1개 + 펼치기). 가로 스크롤은 마지막 수단.

### 10.1 랭킹 화면 (`pages/Ranking.jsx`, `styles/ranking.css`)

- 주소와 상태를 맞춘다: `?type=&date=&world_name=&page=&name=`(오늘 날짜·1쪽은 주소에서 뺀다). 종류·쪽을 바꾸면 기록이 남아 뒤로 가기로 돌아간다.
- 9종 탭(가로 밀기 + 미끄러지는 선택 표시) · 월드(전체/7개) · 날짜(달력 + 하루 전/뒤, 2025-11-27~오늘) · 이름 찾기.
- 한 쪽 50개. 넥슨 API는 200개씩 주므로 API 한 쪽을 받아 화면 4쪽으로 나누고, 같은 API 쪽은 다시 부르지 않는다. 다음 쪽은 받은 행 수로 판단한다(전체 쪽 수는 API가 주지 않는다). 쪽 번호 입력으로 바로 이동.
- **빈 날짜 자동 이동**: 1쪽인데 그날 데이터가 없거나 집계 전이면 하루씩 거슬러 올라간다(캐릭터 7일, 길드 14일). 기준일 안내 띠에 "N월 N일에는 집계된 랭킹이 없어 가장 가까운 이전 집계일로 옮겼어요"를 띄우고 SourceStamp에도 표시한다.
- **이름 찾기**: 캐릭터 랭킹은 이름 → ocid(`/api/maplestorym/id`) → `ranking/<type>?date=&ocid=`로 순위를 얻어 그 쪽으로 이동하고 행을 강조·가운데로 스크롤한다(월드 필터가 있으면 월드 순위로 쪽 계산). 월드 필터가 "전체"면 찾을 월드를 따로 고른다. 길드 랭킹은 이름 조회 API가 없어 그날 상위 200위 안에서 찾는다.
- 월드 필터가 있으면 순위 칸은 월드 순위, 그 아래 작게 전체 순위.
- 1쪽 넓은 화면에서는 상위 3을 단상 카드(스포트라이트·틸트·카운트업)로 먼저 보여준다(모바일은 생략).
- 720px 이상은 표(`<caption>`·`th scope`), 미만은 카드 목록(순위·이름·핵심 수치 + "자세히" 펼치기: 월드·전체/월드 순위·종류별 추가 열). 아바타는 화면에 보일 때만 이미지를 찾는다(`Avatar lazy`).

### 10.2 캐릭터 상세 화면 (`pages/Character.jsx`, `pages/character/*`, `styles/character.css`)

- 데이터: `GET /api/maplestorym/character/page-data` 한 번. 찾지 못하면(400/OPENAPI00004) 안내 + 검색창. 열면 최근 검색에 저장.
- 프로필 머리: 오로라 + 캐릭터 그림(틸트) + 이름(블러 등장) + 레벨·경험치 막대 + **공식 전투력 칩**(`profile.combatPower.official`, 한국식 단위 카운트업 + 순위 + "공식" 배지, 집계일은 SourceStamp에) + 종합 랭킹(랭킹 화면 이름 찾기로 연결) + 길드 + 즐겨찾기 + 기존 화면 링크.
- 주요 스탯: **보스 세팅/현재 착용** 구획 선택 → `majorStats`/`majorStatsCurrent`. 사용 프리셋 칩(보스 세팅이 착용과 다른 칸은 금색 + "착용 N"). 계산 전투력(`statSetting.combatPower`, "추정" 배지, "계산 방법"에 `combatPowerNote`). 8개 스탯 타일(카운트업, 보스 세팅이면 "착용 대비 ±", 억 이상은 한국식 단위 + 전체 값). 타일을 누르면 아래 **출처별 내역**: 분류 비율 막대 → 분류(장비·스킬·성장·콘텐츠·직접 입력) 카드 → 그룹(펼치기) → 항목(출처·값, 원문은 title). 방어율 무시는 곱연산 안내. 화면 값은 page-data의 `displayValue`를 그대로 쓴다(피카츄 보스 세팅 최대 대미지 2,177,400,000 확인).
- **직접 입력 패널**: `GET /api/v2/manual-inputs`(항목 30개·그룹 7개, `groups` 순서를 따름)로 그룹별 접기 목록을 만들고, 숫자 항목은 −/+ 스테퍼(단위·범위 표시), `levels`가 있는 항목은 단계 고르기. "반영하기" → `POST /api/v2/character-stats { world_name, character_name, manual }` → 응답의 `majorStats`·`majorStatsCurrent`·`statSetting`·`majorStatOrder`로 스탯·계산 전투력만 바꾼다(값이 카운트업으로 이전→새 값). 기본값과 같은 칸은 보내지 않는다. 반영 결과: 계산 전투력 전→후·차이, `manualApplied` 목록(단계 이름 포함), `manualWarnings` 개수. 값은 `mmp.manual.<월드>.<이름>`(try/catch, 실패 시 메모리)에 저장하고, 다시 열면 자동으로 다시 계산한다. API가 없으면(404·네트워크 오류) "준비 중"을 보여주고 나머지는 page-data로 동작한다. 반영 중에는 SourceStamp가 "직접 입력" 배지로 바뀌고, 직접 입력이 더해진 스탯 타일에 점이 붙는다.
- 탭(가로 밀기, 주소 `#hash`): 장비 · 스탯(하이퍼 스탯·링크 스킬) · 심볼(아케인·어센틱·쥬얼) · HEXA/V(HEXA 스킬·HEXA 스탯 쪽·V 코어 종류별) · 유니온(등급·레벨 효과·스탯·공격대원) · 길드(요약·기여도·길드원·스킬·건물) · 경험치(요약 + 그래프). 하이퍼·링크·쥬얼은 보스 세팅/현재 착용 기준의 프리셋을 보여준다.
- 장비: 6열×5줄 장비창 배치(가운데 2×3은 캐릭터 그림, 분류 못 한 장비는 아래 줄). 칸 테두리 = 장비 등급 색, 오른쪽 위 = 잠재 등급 글자(R/E/U/L), 왼쪽 아래 = ★스타포스. 프리셋 전환(보스·착용 표시). 마우스를 올리거나 키보드 포커스하면 툴팁, 누르면 시트(모바일은 하단 시트)로 기본·추가·잠재·에디셔널·소울·문장 전체. 세트 효과·소울 세트.
- 경험치 그래프: `exp-history?ocid=`의 날짜별 기록(최근 30일) SVG 선. 하루 넘게 빈 구간은 선을 끊고 "기록 없음" 띠, 읽기 프로그램용 표를 함께 둔다. 기록이 2일 미만이면 빈 상태.
- 파일: `src/styles/`(tokens · base · components · home · design), `src/components/`(AppShell · SearchBox · Card · StatTile · RankBadge · Tabs · Skeleton · States · Avatar · SourceStamp · Icon · Decor), `src/lib/`(format · game · storage · theme · api), `src/pages/`(Home · DesignSystem).
- 브라우저 저장(로그인 없음): `mmp.recent`(최근 검색 10개), `mmp.favorites`(즐겨찾기 20개), `mmp.theme`. 읽을 때 형태·월드를 검사하고, 저장소를 못 쓰면 그 방문 동안 메모리로 동작한다. 다른 탭의 변경도 따라간다.
- 랭킹 미리보기 데이터: 기존 `/api/maplestorym/ranking/<type>?date=YYYY-MM-DD&page=1`에서 상위 5개. 오늘 데이터가 없거나(빈 배열) 집계 전(OPENAPI00009)이면 하루씩 거슬러 올라간다(캐릭터 랭킹 3일, 길드 랭킹 14일). 같은 종류는 화면을 보는 동안 한 번만 요청한다.

## 11. 남은 과제

- SUIT 두 굵기가 약 340KB다. 만든 사람이 범위별 조각 배포본을 내면 그걸로 바꾼다(직접 자르면 OFL 예약 이름 문제).
- 랭킹: 전체 쪽 수를 몰라 "다음"만 판단한다. 순위 변동(전날 대비 ▲▼)은 서버가 전날 순위를 함께 주면 넣는다. 길드 이름 찾기는 상위 200위까지만.
- 캐릭터 상세: 캐시 장비·안드로이드·스킬 프리셋은 아직 기존 화면에만 있다. 공유 이미지·카카오 공유, 갱신 버튼(쿨다운), `og:*` 메타 주입(서버)도 남았다.
- 직접 입력 패널은 항목이 30개라 길다. 직업 계열(`jobFamily`) 안내, 항목별 "이 값이 바꾸는 스탯"(`appliesTo`) 표시를 더할 수 있다.
- 큰 수 전체 값: 지금은 마우스 오버(`title`)만. 모바일 길게 누르기·키보드 포커스로 보여주는 툴팁 필요.
- 전체 화면 검색 시트(모바일 다른 화면용), `Toast`·확인 `Dialog`(`Sheet`·카운트업은 v0.3에서 구현).
- 즐겨찾기·최근 검색 아바타가 항목마다 썸네일 API를 부른다(서버 12시간 캐시, 브라우저 1시간 캐시). 항목이 많아지면 이미지 주소를 저장값에 함께 두는 방식 검토.
- 기존 상세 화면에서 검색한 기록은 `mmp.recent`에 남지 않는다(상세 화면을 새로 만들 때 연결).
