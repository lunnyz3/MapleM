## 4. 사이트와 다르게 정한 규칙

두 사이트가 같으면 그대로 따랐다. 다를 때 고른 쪽과 근거:

| 항목 | maplemworlds | maplemtool | 우리 | 근거 |
|---|---|---|---|---|
| 공격력%·대미지 패시브 | 상수 300·60 | 직업 패시브 50·35 + V 코어 레벨 | maplemtool | V 코어 공식은 운영자 확인값. 만렙이면 두 방식이 같다 |
| 그 밖의 장비 세트(군단장·보스 전리품·160제·루타비스·차원 균열 등) | 넣지 않음 | 넣음 | maplemtool | 넥슨 set-effect API가 현재 착용 세트로 이 효과를 보고한다 |
| 160제·루타비스·도전자 스타포스 세트, 앱솔 빌림 | 없음 | 있음 | maplemtool | 같은 이유, 2026-07-30 '세트옵션 자동 보정' |
| 앱솔 스타포스 70구간 최대 대미지 | 500만 | 550만 | 550만 | 공식 스크린샷(docs/game-data-audit.md G05) |
| 소울 세트 공격력 | 자체 표(칼로스·카링 등 0) | API soul_set_option | API | 넥슨 API가 프리셋마다 값을 준다 |
| 레벨 기본 공격력 | 기준점 보간 | 자체 표(14~16 큼) | maplemworlds | 두 표 모두 실측 섞임. 깡공이 maplemworlds와 정확히 맞는다 |
| 소울 게이지 +30 | 넣음 | 없음 | maplemworlds | 기본은 maplemworlds |
| 방어율 무시 곱연산 | 옵션 줄마다(아케인 세트+스타포스만 합산) | 아이템·세트 이름별 합산 후 | maplemworlds | 운영자 지정 기준 |
| 본인 링크 | 항상 더함 | 장착 링크와 합쳐 최대 레벨에서 자름 | maplemtool | 상한 미만이면 같다 |
| 추가 옵션 대미지 7.74% | 그대로 | 7.745로 보정 | maplemworlds | 표시 반올림 보정이라 근거 약함 |
| 사냥용 링크 프리셋(엘프의 축복 경험치) | 보스 세팅 후보에서 뺌 | 후보에 넣음 | maplemtool | 운영 정의(프리셋 조합 중 계산 전투력 최고). 조합 수도 maplemtool 표시와 같다(디올 324, 피카츄 144). game-data 스위치 excludeFromBossSetting |

두 사이트와 같게 둔 기본 조건:

- 넥슨 API에 없는 수동 입력(스타코러스, 컨스텔라 코어, 유니온 챔피언, 축복, 성흔, 명예 배지, 몬스터 컬렉션, 펫 깡공)은 기본 0이다. 그래서 계산 전투력은 공식 랭킹 전투력보다 낮다(두 사이트 중앙값 기준 공식이 약 1.29배, README 2-2). 화면에는 '계산 전투력(추정)'으로 표시한다. 사용자가 '직접 입력'(POST /api/v2/character-stats, 항목 src/game-data/manual-inputs.json)으로 넣으면 더하고 보스 세팅 조합도 다시 고른다(7장). 컨스텔라 코어는 두 사이트처럼 전투력 밖이다.
- 성흔 세트(API 세트명에 '성흔')와 길드 공용 스킬은 넣지 않는다. 지하수로·전장 전용 길드 어빌리티도 뺀다.
- 깡공은 넥슨 API 능력치 값이 아니라 출처 합 + 레벨 기본 공격력으로 만든다.
- 전투력 공식에 방어율 무시와 치명타 확률은 들어가지 않는다.

## 7. 직접 입력 대조 (maplemworlds 인증 캐릭터)

maplemworlds 인증 캐릭터는 수동 입력이 서버에 저장돼 화면 합계에 들어 있다. 그 화면의 수동 입력 항목(스타코러스·성흔·축복·유니온 챔피언·명예 배지·몬스터 컬렉션·펫)을 우리 직접 입력 항목으로 옮겨 넣고(scripts/dev/calibration-report.js `MW_MANUAL_INPUTS`), 그 사이트가 고른 보스 세팅 조합으로 다시 계산했다.

- '입력 기여'는 우리 엔진에서 직접 입력이 더한 값, 'mw 입력 항목'은 그 사이트 화면의 수동 입력 항목 합(방어율 무시는 곱연산으로 환산)이다. 둘이 같으면 입력 규칙이 같다는 뜻이다.
- '합계 차이'는 직접 입력을 넣은 우리 합계 − 그 사이트 화면 합계다. 남는 차이는 입력과 무관한 1·4장의 규칙 차이다.
